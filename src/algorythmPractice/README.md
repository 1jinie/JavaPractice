# 1. 숫자 맞추기 게임
## 구현 조건
1. 정답은 반드시 1~100 사이의 정수
2. 정답을 프로그램 실행 전에 직접 지정하면 안됨
3. 정답을 맞힐 때까지 반복
4. 정답을 맞히면 시도 횟수를 출력해야 함
5. 정답을 맞힌 이후에는 추가 입력을 받으면 안 됨
6. Math.random() 대신 Random 클래스 사용

## 실행 예시
```
===== 숫자 맞추기 게임 =====
1부터 100 사이의 숫자를 맞혀보세요!

숫자를 입력하세요: 30
더 큰 숫자입니다.

숫자를 입력하세요: 80
더 작은 숫자입니다.

숫자를 입력하세요: 60
더 작은 숫자입니다.

숫자를 입력하세요: 57
정답입니다!
축하합니다!
시도 횟수: 4회

===== 게임 종료 =====
```

## 추가 과제
1. 입력값 유효성 검사
2. 게임 재시작 기능
3. 난이도 설정(1:쉬움[1~50], 2:보통[1~100], 3:어려움[1~500])

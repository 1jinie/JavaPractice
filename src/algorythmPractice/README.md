# 1. 숫자 맞추기 게임
## A. 구현 조건
1. 정답은 반드시 1~100 사이의 정수
2. 정답을 프로그램 실행 전에 직접 지정하면 안됨
3. 정답을 맞힐 때까지 반복
4. 정답을 맞히면 시도 횟수를 출력해야 함
5. 정답을 맞힌 이후에는 추가 입력을 받으면 안 됨
6. Math.random() 대신 Random 클래스 사용

## B. 실행 예시
```
===== 숫자 맞추기 게임 =====
1부터 100 사이의 숫자를 맞혀보세요!

숫자를 입력하세요: 30
더 큰 숫자입니다.

숫자를 입력하세요: 80
더 작은 숫자입니다.

숫자를 입력하세요: 60
더 작은 숫자입니다.

숫자를 입력하세요: 57
정답입니다!
축하합니다!
시도 횟수: 4회

===== 게임 종료 =====
```

## C. 추가 과제
1. 입력값 유효성 검사
2. 게임 재시작 기능
3. 난이도 설정(1:쉬움[1~50], 2:보통[1~100], 3:어려움[1~500])

# 2. 로또 번호 생성 및 중복 검사
## A. 프로젝트 목표
- 1 ~ 45까지 숫자 중 6개 선택
- 한 게임 안에서 중복 번호 허용x 
- 생성된 번호는 오름차순 정렬 
- 여러 게임 생성 가능

## B. 필수 요구사항
1. 생성 개수 입력 : 사용자에게 몇 게임 생성할지 입력
2. 입력값 검증 : 1보다 작은 수나 숫자 아닌 값 입력시 재입력 받음
3. 로또 번호를 생성 : 1 ~ 45 사이 숫자 6개 생성
4. 중복 번호 검사 : 이미 생성된 번호가 배열에 존재하는지 검사
5. 중복 번호 방지 : 중복 숫자가 나오면 배열에 저장하지 않고 재생성
6. 배열 활용 : 생성한 번호 6개 정수 배열에 저장
7. 번호 정렬 : 생성된 번호 오름차순 정렬
8. 생성 결과 출력 : 각 게임의 로또번호 출력
9. 재시작 기능 : 모든 번호 생성 끝나면 재생성할지 물어봄
10. 잘못된 재시작 입력 처리 : y/n 이외값 입력시 재입력 받음

## C. 실행 예시
```
===== 로또 번호 생성 프로그램 =====

생성할 게임 수를 입력하세요: 3

===== 로또 번호 생성 결과 =====

1번 게임: 3, 12, 18, 25, 34, 41
2번 게임: 5, 9, 16, 22, 37, 44
3번 게임: 1, 11, 20, 28, 32, 45

총 3게임 생성 완료

다시 생성하시겠습니까?(y/n): y

===== 로또 번호 생성 프로그램 =====

생성할 게임 수를 입력하세요: 3

===== 로또 번호 생성 결과 =====

1번 게임: 7, 14, 19, 23, 31, 42
2번 게임: 2, 8, 17, 26, 35, 40 

총 2게임 생성 완료

다시 생성하시겠습니까?(y/n): n

===== 프로그램 종료 =====
```

## D. 추가 과제
1. 보너스 번호 생성
   - 기본 번호 6개 외 보너스 번호 1개 생성
   - 기존 6개 번호와 중복 x
2. 수동 번호 입력
   - 사용자가 직접 6개 번호 입력
   - 1 ~ 45 범위 검사
   - 중복 번호 검사
3. 생성된 번호 통계
   - 전체 게임에서 가장 많이 등장한 숫자 찾기
   - 가장 적게 등장한 숫자 찾기
